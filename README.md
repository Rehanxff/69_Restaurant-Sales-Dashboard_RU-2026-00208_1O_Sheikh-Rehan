# Project Description

The Restaurant Sales Dashboard reads restaurant sales data from a CSV file using Pandas. It calculates sales using:

Sales = Quantity × Price**

The program displays sales summaries and creates charts to help understand restaurant sales.

# Features

1. Load restaurant sales data from a CSV file.
2. Check required columns and skip invalid rows.
3. Handle a missing CSV file without crashing.
4. Calculate total sales and total quantity sold.
5. Display sales category-wise.
6. Find the top-selling item by quantity.
7. Find the top item by revenue.
8. Display day-wise sales and the best sales day.
9. Show bar, line, and pie charts.
